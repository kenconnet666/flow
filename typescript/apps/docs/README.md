# 流程引擎文档站

用 vue-tsx-pro 组件库写的 TSX 网站（同组件库自己的文档站：AppShell 外壳、左侧导航、本页目录、上一篇 / 下一篇），
介绍流程引擎：给业务人员的使用与搭建教程（带配图），给管理员的运维，给程序员的接入与扩展。

```bash
pnpm -C apps/docs dev       # http://localhost:5190
pnpm -C apps/docs build
pnpm -C apps/docs shots     # 重新截图：先起示例后端（8080）与示例前端（5180），截到 public/shots
```

## 目录

- `src/site/`：站点的骨架——导航数据 `nav.ts`、文档页 `DocPage`、配图 `Shot`、操作步骤 `Steps` 的用法
- `src/pages/<分组>/`：每页一个 TSX 文件，导出 `meta`（标题、简介）与默认组件
- `shots/`：截图脚本（Playwright，按教程一步步真实操作示例前端，边做边截）；图存 `public/shots/<页>/<序号>-<名字>.png`

## 大纲

| 分组 | 页面 |
| --- | --- |
| 开始 | 介绍（能做什么、架构一张图）、快速体验（跑起示例） |
| 日常使用 | 发起与草稿、待办与办理、协作（转办、委派、加签、退回、撤回、催办、留言、抄送）、我发起的与流程详情 |
| 搭建流程 | 设计器入门、教程 1 报销（条件分支）、教程 2 采购评审（并行与会签）、教程 3 合同审批（起草、退回、上一步选人、抄送）、教程 4 出差申请（包容分支与定时）、教程 5 大额采购（子流程）、教程 6 外部签约（自动处理与外部事件） |

| 管理 | 流程管理与版本、流程监控与干预（暂停、跳转、改派、改数据、迁移）、异常处理、工作日历与统计 |

内容以仓库里的设计文档（`docs/decisions/0001`–`0008`）与接入文档（`docs/integration.md`）为准；页面写法跟组件库的文档站一致。
